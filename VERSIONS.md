## Roadmap

### v2.9: Low-Latency Context (Short-term)
- **Websocket Integration**: Move from 1H polling to real-time websocket data for OBI and Price.
- **Dynamic Pyramiding**: Allow the agent to add to winning positions during high-conviction trends.
- **Multimodal Context**: Use LLMs to parse real-time "Breaking News" headlines from X (Twitter).

### v3.0: Full Neuro-Symbolic Institutional Fund (Long-term)
- **Reinforcement Learning (RL)**: Replace simple rules with deep RL agents for execution optimization.
- **Multi-Exchange Coordination**: Trade across Hyperliquid, Binance, and dYdX simultaneously.
- **On-Chain Alpha**: Integrate whale wallet tracking and CEX-to-DEX flow analysis as primary factors.
- **Hardware Acceleration**: Move critical logic to FPGA/ASIC for microsecond execution (The "Institutional" Phase).
